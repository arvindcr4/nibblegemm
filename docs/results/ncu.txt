    Metric Name                                           Metric Unit Metric Value
    dram__bytes.sum.per_second                                Gbyte/s        51.42
    launch__registers_per_thread                      register/thread          128
    sm__inst_executed_pipe_tensor.sum                            inst   33,554,432
    sm__throughput.avg.pct_of_peak_sustained_elapsed                %        39.64
    sm__warps_active.avg.pct_of_peak_sustained_active               %        24.31
    smsp__inst_executed.sum                                      inst  319,463,424

# Reading: 128 registers/thread at 256 threads/block is exactly 2 blocks per SM
# on a 65536-register SM, which is where the 24.3% occupancy comes from.
# 319,463,424 / 33,554,432 = 9.52 instructions issued per tensor instruction --
# the kernel is issue-bound on addressing and shared-memory bookkeeping, not on
# math. Low DRAM throughput is expected here: at M=4096 the weights are reused
# across rows, so this regime is compute-bound by construction.
#
# The tensor count checks out against the shape: (M/16)(N/16)(K/16) = 16,777,216
# wmma 16x16x16 ops, each issuing 2 HMMA.16816 = 33,554,432.
